Copy Script Files

Tap a button to copy that whole file, then paste it into Apps Script over everything that's there. The line count lets you check nothing was cut off.

How to paste
  1. In the Google Sheet, open Extensions → Apps Script.
  2. Click the file with the same name on the left (make it with + if it's missing).
  3. Click inside the code, press Ctrl/Cmd + A, then paste.
  4. Check the last line in Apps Script matches the one shown here, then save.
  5. Finish with Deploy → Manage deployments → ✏️ → New version → Deploy.
